# RickAndMorty

SwiftUI აპი iPhone-ისა და iPad-ისთვის. მინიმალური ვერსიაა iOS 17.6. გასაშვებად გახსენი `RickAndMorty.xcodeproj`, აირჩიე `RickAndMorty` scheme და გაუშვი `⌘R`-ით. ცოცხალი მონაცემებისა და სურათებისთვის საჭიროა ინტერნეტი.

კოდის გასარჩევად ამ თანმიმდევრობას მიჰყევი.

1. `RickAndMortyApp.swift` ქმნის `URLSessionAPIClient`-ს და Repository-ს, შემდეგ გადასცემს მათ ეკრანებს.
2. `CharacterListView.swift` აჩვენებს სიას, იღებს search ტექსტს და ფილტრის არჩევანს. `CharacterListViewModel.swift` მართავს request-ის შედეგს, შემდეგი გვერდის მისამართს და Retry-ს. ახალი search/filter აყენებს სიის ახალ მდგომარეობას. ძველი პასუხები ახალ შედეგებს ვერ გადაწერს.
3. `CharactersRepository.swift` არჩევს API რესურსს. `URLRequestBuilder.swift` აწყობს URL-ს და ერთ ადგილას ადგენს headers-სა და timeout-ს. `APIClient.swift` ამოწმებს HTTP status-ს და JSON-ს DTO-დ გარდაქმნის.
4. `CharacterDetailsViewModel.swift` იღებს პერსონაჟის დეტალებსა და ეპიზოდებს. მონაწილეები კონკრეტული სექციის გაშლისას იტვირთება. Repository მიმდინარე პერსონაჟს გამორიცხავს და ყველა სხვა მონაწილეს ჯგუფებად იღებს. შედეგები ეპიზოდის თავდაპირველი რიგით ბრუნდება.
5. `CharacterAvatar.swift` გამოიყენება სიაში, დეტალებსა და მონაწილეებთან. მას აქვს loading მდგომარეობა და placeholder. მონაწილეზე დაჭერისას `NavigationStack` შესაბამის ID-ზე გადადის.

`⌘U` გაუშვებს Swift Testing ტესტებს. `RecordingAPIClient` ინახავს გაგზავნილ requests-ს და აბრუნებს წინასწარ განსაზღვრულ JSON-ს. ამ გზით ტესტებში ინტერნეტი არ გვჭირდება.

- ძებნისა და ფილტრების ტესტი ამოწმებს, რომ სახელის გარშემო spaces იშლება, ფილტრები ერთ request-ში ერთიანდება და პასუხიდან იკითხება პერსონაჟი და pagination.
- მონაწილეების ტესტი იყენებს 21 მონაწილეს მიმდინარე პერსონაჟის გამოკლების შემდეგ. ამოწმებს, რომ მეორე request-იც გაიგზავნა, შედეგი არ შეიკვეცა და რიგი შენარჩუნდა მაშინაც, როცა API პირველი ჯგუფის წევრებს შებრუნებული რიგით აბრუნებს.
- pagination-ის ტესტი ამოწმებს დუბლიკატის გამოტოვებას და იმას, რომ ბოლო გვერდის შემდეგ request აღარ იგზავნება.
- pagination error-ის ტესტი ამოწმებს, რომ წარუმატებელი მეორე გვერდის შემდეგ პირველი გვერდი ჩანს და Retry-სთვის მისამართი ინახება.

ძირითად ფუნქციონალში შედის server search/filter, უსასრულო სია, Character Details, expandable episodes, მონაწილეთა ჰორიზონტალური სია და მათ დეტალებზე გადასვლა. iPhone/iPad-ზე ორივე orientation ჩართულია. Offline caching და localization დამატებითი ეტაპებია.
